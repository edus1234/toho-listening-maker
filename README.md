# リスニングテスト自動作成システム

英語のリスニングテストの原稿・音声・問題を自動で作成するWebアプリケーションです。

## 🌐 公開URL

- **開発環境**: https://3000-ijna95podvgmovwjfqaet-82b888ba.sandbox.novita.ai
- **APIヘルスチェック**: https://3000-ijna95podvgmovwjfqaet-82b888ba.sandbox.novita.ai/api/health

## ✨ 実装済み機能

### 1. スクリプト条件入力フォーム
- **形式選択**: モノローグ（1人）またはダイアローグ（複数人）
- **トピック入力**: リスニングのテーマを指定
- **キーワード指定**: 含めるべき単語をカンマ区切りで入力
- **CEFRレベル選択**: A1〜C2の6段階から選択
- **その他条件**: 詳細な要件を自由記述（人数指定など）

### 2. リスニング問題設定画面
- **長め + 問題2-3題**: 詳細なスクリプトと複数の問題
- **短め + 問題1題**: コンパクトなスクリプトと基本問題
- 問題作成の有無を選択可能

### 3. 原稿確認・編集画面
- 生成されたスクリプトの表示
- **キャラクター名自動付与**: ランダムに選ばれた英語名を使用
- **完全英語スクリプト**: 日本語の混入を防止
- スクリプトの編集機能
- 問題の表示（問題作成を選択した場合）
- 再生成機能

### 4. 音声設定画面 ⭐NEW
- **話者ごとのアクセント選択**: 
  - アメリカ英語 (US)
  - イギリス英語 (UK)
  - オーストラリア英語
  - カナダ英語
  - インド英語
  - アイルランド英語
  - スコットランド英語
- **話者ごとの速度調整**: 0.5x〜1.5x（0.1刻み）
- 各話者の設定を個別にカスタマイズ可能

### 5. 音声生成と再生画面 ⭐NEW
- 音声ファイルの自動生成（APIエンドポイント実装済み）
- 音声プレイヤーでの再生
- 話者情報の表示
- 音声ダウンロード機能

## 🚀 機能の流れ

1. **ステップ1**: スクリプト条件を入力
   - 形式、トピック、キーワード、CEFRレベル、その他条件を設定
   - 「併せてリスニング問題も作成する」にチェックを入れると問題も自動生成

2. **ステップ2**: 問題設定（問題作成を選択した場合）
   - 「長め + 問題2-3題」または「短め + 問題1題」を選択

3. **ステップ3**: 原稿の確認と編集
   - 自動生成されたスクリプトを確認（純粋な英語）
   - 必要に応じて編集可能
   - 問題も表示（作成を選択した場合）

4. **ステップ4**: 音声設定 ⭐NEW
   - 各話者のアクセントを選択（US, UK, Indian等）
   - 各話者の速度を調整（0.5x〜1.5x）

5. **ステップ5**: 音声生成と完了 ⭐NEW
   - 音声ファイルを自動生成
   - ブラウザで音声を再生
   - 音声ファイルをダウンロード

## 📝 データモデル

### スクリプト設定
- `format`: 形式（monologue/dialogue）
- `topic`: トピック
- `keywords`: キーワード（カンマ区切り）
- `cefrLevel`: CEFRレベル（A1〜C2）
- `otherConditions`: その他条件
- `createQuestions`: 問題作成の有無
- `questionSettings`: 問題設定（long/short）

### 生成されるデータ
- `generatedScript`: 生成されたスクリプト（純粋な英語）
- `generatedQuestions`: 生成された問題（配列）
  - `question`: 問題文
  - `options`: 選択肢（配列）
  - `correctAnswer`: 正解
- `speakers`: 話者情報（配列）
  - `name`: 話者名
  - `accent`: アクセント（US/UK/Indian等）
  - `speed`: 話速（0.5〜1.5）
- `generatedAudio`: 生成された音声ファイルのURL

## 📞 使い方

1. ブラウザで公開URLにアクセス
2. リスニングスクリプトの条件を入力
   - トピック: 「環境問題」
   - キーワード: 「global warming, climate change」
   - その他条件: 「3人の学生が話している」など
3. 必要に応じて「併せてリスニング問題も作成する」にチェック
4. 問題設定を選択（チェックした場合）
5. 生成されたスクリプトを確認・編集
6. **音声設定**で各話者のアクセントと速度を調整
7. 音声を生成して再生・ダウンロード
