# リスニングテスト自動作成システム

英語のリスニングテストの原稿・音声・問題を自動で作成するWebアプリケーションです。

## 🌐 公開URL

- **開発環境**: https://3000-ijna95podvgmovwjfqaet-82b888ba.sandbox.novita.ai
- **APIヘルスチェック**: https://3000-ijna95podvgmovwjfqaet-82b888ba.sandbox.novita.ai/api/health

## ✨ 実装済み機能

### 1. スクリプト条件入力フォーム
- **形式選択**: モノローグ（1人）またはダイアローグ（複数人）
- **トピック入力**: リスニングのテーマを指定
- **キーワード指定**: 含めるべき単語をカンマ区切りで入力
- **CEFRレベル選択**: A1〜C2の6段階から選択
- **対話の人数設定** ⭐NEW: ダイアローグの場合、2〜5人から選択
- **各話者の国籍設定** ⭐NEW: 
  - アメリカ
  - イギリス
  - オーストラリア
  - カナダ
  - インド
  - アイルランド
  - スコットランド
  - 南アフリカ
  - ニュージーランド
  - シンガポール
- **その他条件**: 詳細な要件を自由記述（シチュエーションなど）

### 2. リスニング問題設定画面
- **長め + 問題2-3題**: 詳細なスクリプトと複数の問題
- **短め + 問題1題**: コンパクトなスクリプトと基本問題
- 問題作成の有無を選択可能

### 3. 原稿確認・編集画面
- 生成されたスクリプトの表示
- **キャラクター名自動付与**: ランダムに選ばれた英語名を使用
- **完全英語スクリプト**: 日本語の混入を防止
- スクリプトの編集機能
- 問題の表示（問題作成を選択した場合）
- 再生成機能

### 4. 音声設定画面 ⭐NEW
- **スクリプト各セリフの表示とブランク設定**:
  - 各セリフのテキストを表示
  - ナレーション/対話の区別
  - セリフごとに後のブランク時間を設定（0〜10秒）
- **セリフごとのSSML音声指示** 🆕:
  - 各セリフに個別の音声制御指示を追加可能
  - **速度調整**: `<prosody rate="fast">速く話す</prosody>`
  - **ピッチ調整**: `<prosody pitch="+2st">上げ調子</prosody>`
  - **ブレイク（間）**: `カンマの後に<break time="0.5s"/>ブレイク`
  - **強調**: `<emphasis level="strong">ここを強調</emphasis>`
  - 特定の単語や文節を細かく制御可能
- **ナレーション機能** ⭐NEW:
  - 英語または日本語のナレーション追加
  - 自動言語検出
  - **音声の最初に配置**
- **話者ごとのアクセント選択**: 
  - アメリカ英語 (US)
  - イギリス英語 (UK)
  - オーストラリア英語
  - カナダ英語
  - インド英語
  - アイルランド英語
  - スコットランド英語
- **話者ごとの詳細設定**:
  - 性別選択（男声/女声） ⭐NEW
  - 速度調整: 0.5x〜1.5x（0.1刻み）
- **問題読み上げ設定** ⭐NEW:
  - 問題読み上げ話者の性別選択（男声/女声）
  - アクセント選択（US/UK/Australian等）
  - 速度調整（0.5x〜1.5x）
  - 問題後のブランク時間設定
  - 選択肢間のブランク時間設定
  - ラベル重複修正済み（"A. A) Text" → "A) Text"）

### 5. 音声生成と再生画面 ⭐NEW
- **Google Text-to-Speech API統合**:
  - 実際の音声生成（モックではなく本物のTTS）
  - 多言語対応（英語/日本語）
  - 高品質な音声合成
- **セグメント別表示**:
  - 各セグメントのテキスト表示 ⭐NEW
  - セグメントタイプの視覚的区別（ナレーション/対話/問題/選択肢）
  - ブランク時間の表示
- **再生機能**:
  - セグメント別の個別再生
  - 全セグメント連続再生
  - ブランクを含む自然な再生
- **ダウンロード機能**:
  - 結合されたMP3ファイルのダウンロード
  - ファイル名: listening-test.mp3

## 🚀 機能の流れ

1. **ステップ1**: スクリプト条件を入力
   - 形式、トピック、キーワード、CEFRレベルを設定
   - **ダイアローグの場合**: 対話の人数（2〜5人）と各話者の国籍を選択
   - その他条件（シチュエーションなど）を記述
   - 「併せてリスニング問題も作成する」にチェックを入れると問題も自動生成

2. **ステップ2**: 問題設定（問題作成を選択した場合）
   - 「長め + 問題2-3題」または「短め + 問題1題」を選択

3. **ステップ3**: 原稿の確認と編集
   - 自動生成されたスクリプトを確認（純粋な英語）
   - 必要に応じて編集可能
   - 問題も表示（作成を選択した場合）

4. **ステップ4**: 音声設定 ⭐NEW
   - 各セリフのテキストを確認し、後のブランク時間を個別設定
   - ナレーションを追加（音声の最初に配置）
   - 各話者の性別、アクセント、速度を設定
   - 問題読み上げ設定（性別、アクセント、速度、ブランク）

5. **ステップ5**: 音声生成と完了 ⭐NEW
   - Google TTSで実際の音声を生成
   - セグメント別にテキストと音声を確認
   - 個別再生または連続再生
   - MP3ファイルをダウンロード

## 📝 データモデル

### スクリプト設定
- `format`: 形式（monologue/dialogue）
- `topic`: トピック
- `keywords`: キーワード（カンマ区切り）
- `cefrLevel`: CEFRレベル（A1〜C2）
- `otherConditions`: その他条件
- `createQuestions`: 問題作成の有無
- `questionSettings`: 問題設定（long/short）

### 生成されるデータ
- `generatedScript`: 生成されたスクリプト（純粋な英語）
- `generatedQuestions`: 生成された問題（配列）
  - `question`: 問題文
  - `options`: 選択肢（配列）
  - `correctAnswer`: 正解
- `speakers`: 話者情報（配列）
  - `name`: 話者名
  - `gender`: 性別（male/female）
  - `accent`: アクセント（US/UK/Indian等）
  - `speed`: 話速（0.5〜1.5）
  - `pauseAfter`: セリフ後のブランク（秒）
- `parsedLines`: 解析されたスクリプト行（配列）
  - `type`: タイプ（narration/dialogue）
  - `speaker`: 話者名
  - `text`: セリフのテキスト
  - `pauseAfter`: 後のブランク時間（秒）
- `questionReader`: 問題読み上げ設定
  - `gender`: 性別（male/female）
  - `accent`: アクセント
  - `speed`: 話速（0.5〜1.5）
  - `questionPause`: 問題後のブランク（秒）
  - `optionPause`: 選択肢間のブランク（秒）
- `audioSegments`: 生成された音声セグメント（配列）
  - `speaker`: 話者名
  - `audio`: Base64エンコードされた音声データ
  - `pauseAfter`: 後のブランク時間
  - `type`: セグメントタイプ（narration/dialogue/question/option）
  - `text`: セリフテキスト

## 📞 使い方

1. ブラウザで公開URLにアクセス
2. リスニングスクリプトの条件を入力
   - トピック: 「環境問題」
   - キーワード: 「global warming, climate change」
   - その他条件: 「3人の学生が話している」など
3. 必要に応じて「併せてリスニング問題も作成する」にチェック
4. 問題設定を選択（チェックした場合）
5. 生成されたスクリプトを確認・編集
6. **音声設定**で詳細設定
   - 各セリフのブランク時間を調整
   - **SSML音声指示を追加**（速度、ピッチ、間、強調）
   - 必要に応じてナレーションを追加
   - 話者の性別、アクセント、速度を設定
   - 問題読み上げの設定
7. 音声を生成して再生・ダウンロード
